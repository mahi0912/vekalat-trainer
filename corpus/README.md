# پیکرهٔ قوانین

هر فایل، متن یک قانون است با سرفصل یکدستِ `ماده N – متن`، تا
`scratchpad/corpus.py` بتواند تفکیکش کند. دو تلهٔ فایل‌ها را همان‌جا مستند کرده‌ایم:
مواد اصلاحی که پرانتز دارند (`ماده ۱۳۷ (اصلاحی ۱۳۹۹/۲/۲۳) –`) و ارجاع‌های
درون‌متنی به شکل `ماده ۱۱۸- ۱۱۹- ۱۲۰` که شروع مادهٔ تازه نیستند.

## فهرست منابع رسمی آزمون وکالت، و وضعیت هر کدام

برگرفته از فهرست «قوانین خاص حقوقی و کیفری منبع آزمون وکالت» (اختبار / نشر دادبازار،
ویرایش ششم ۱۴۰۴)، منطبق با منابع اعلام‌شدهٔ اسکودا و مرکز وکلای قوه قضائیه.
