# سؤالات فقهِ دوره‌های قدیمی کانون

متنِ بخش «اصول استنباط حقوق اسلامی» از دفترچه‌های ۱۳۹۰ تا ۱۳۹۹، استخراج‌شده از PDF دفترچه‌ها.

- `1390-1391-1394-with-keys.json` — ۶۰ سؤال با **کلید رسمی** (این سه دفترچه پاسخنامه داشتند).
- `1392.txt` `1395.txt` `1396.txt` `1399.txt` — متنِ سؤالات، **بدون کلید**.

نکتهٔ مهم: در دوره‌های ۱۳۹۰ تا ۱۳۹۹ این درس «اصول استنباط حقوق اسلامی» بود و **هیچ متن عربی نداشت**؛
متون فقه از ۱۴۰۰ به بعد اضافه شده است.

دفترچه‌های ۱۳۹۳ و ۱۳۹۷ و دفترچهٔ کرمانشاه تصویری‌اند (لایهٔ متنی ندارند) و استخراج نشدند.

تحلیل جمع‌بندی‌شدهٔ این داده‌ها در صفحهٔ «نقشهٔ سؤال فقه» است.
