# مربی آزمون وکالت مرکز وکلا

اپلیکیشن وب استاتیک برای تمرین ۹۱۰ سؤال واقعی آزمون وکالت مرکز وکلا (۱۳۹۸ تا ۱۴۰۴)
همراه با تصویر اصل دفترچه، تحلیل حقوقی چهارگزینه‌ای، نمره‌دهی با نمره منفی و
گزارش نقاط قوت و ضعف به تفکیک واحد درسی.

**نشانی سایت:** https://mahi0912.github.io/vekalat-trainer/

## ساختار پروژه

```
site/
  index.html            اسکلت صفحه (بدون منطق)
  auth-config.js        هش پسورد — هنگام دیپلوی تزریق می‌شود
  bank.json             ← منبع حقیقت داده‌ها؛ همه چیز از رویش ساخته می‌شود
  css/styles.css        سیستم طراحی، پوسته روشن و تیره
  js/gate.js            دروازه ورود
  js/app.js             کنترل‌گر: مسیریابی، رویدادها، میان‌برهای صفحه‌کلید
  js/views.js           ساخت HTML صفحه‌ها
  js/state.js           جلسه آزمون، ذخیره محلی، نمره‌دهی
  js/data.js            بارگذاری داده
  js/util.js            ابزارهای مشترک
  js/groups.js          گروه‌بندی دروس و واحدها
  data/                 ← ساخته می‌شود (در گیت نیست)
  assets/<سال>/*.jpg    تصاویر صفحات دفترچه
scripts/
  build_data.py         ساخت data/ از bank.json
  verify_site.py        اعتبارسنجی سؤالات، تحلیل‌ها و تصاویر
  check_js.py           بررسی نحوی و صحت importها
  run_tests.py          اجرای tests/
  inject_password.py    ساخت هش پسورد هنگام بیلد
tests/
  state_test.js         تست نمره‌دهی و نقاط قوت/ضعف
  views_test.js         تست رندر نماها و خنثی‌سازی HTML
  fixture.json          نمونه داده واقعی برای تست‌ها
```

## اجرای محلی

```bash
python3 scripts/build_data.py          # ساخت site/data از bank.json
python3 -m http.server 8000 --directory site
# سپس http://localhost:8000
```

در اجرای محلی دروازه ورود نمایش داده نمی‌شود (`auth-config.js` هنوز placeholder دارد).

## بررسی‌ها

```bash
python3 scripts/check_js.py      # نحو جاوااسکریپت و صحت importها
python3 scripts/run_tests.py     # تست منطق نمره‌دهی
python3 scripts/verify_site.py   # یکپارچگی داده و تصاویر
```

هر سه در CI هم اجرا می‌شوند و اگر شکست بخورند، دیپلوی انجام نمی‌شود.

## معماری داده

`bank.json` تنها منبع حقیقت است. `build_data.py` آن را می‌شکند تا مرورگر فقط چیزی
را دانلود کند که لازم دارد:

| فایل | حجم | چه زمانی |
|---|---|---|
| `data/questions.json` | ~۷۷۰ KB | یک‌بار در شروع — متن سؤال، گزینه‌ها، کلید، تصاویر |
| `data/review/<سال>.json` | ~۳۰۰-۴۸۰ KB | فقط هنگام نمایش نتیجه، فقط سال‌های همان جلسه |
| `data/meta.json` | چند KB | شمارش‌ها |

فیلدهایی مثل `searchText` و `scrollRatio` که رابط کاربری استفاده نمی‌کند منتشر
نمی‌شوند. پیش از این کل ۵٫۳ مگابایت پیش از دیدن صفحه اول دانلود می‌شد.

## نمره‌دهی

- **درصد خام** = صحیح ÷ کل
- **درصد با نمره منفی** = (صحیح − غلط×⅓) ÷ کل — مطابق شیوه آزمون مرکز وکلا؛
  هر سه پاسخ غلط یک پاسخ صحیح را خنثی می‌کند. ضریب در `PENALTY` داخل `js/state.js` است.
- **نقاط قوت و ضعف** بر پایه درصد هر واحد درسی، فقط برای واحدهایی با دست‌کم ۳ سؤال
  در آن آزمون (نمونه کمتر برای قضاوت کافی نیست).

## دروازه ورود

پسورد به شکل متن ساده در مخزن نیست؛ فقط خروجی PBKDF2-SHA256 آن ذخیره می‌شود و
مقدار واقعی هنگام دیپلوی از سکرت `WEBAPP_PASSWORD`
(Settings → Secrets and variables → Actions) تزریق می‌شود. برای تغییر پسورد کافی است
مقدار سکرت را عوض کنید و workflow را دوباره اجرا کنید — نیازی به کامیت نیست.

> ### ⚠️ این دروازه امنیت واقعی نیست
>
> مخزن و سایت هر دو عمومی‌اند. یعنی `data/questions.json` و تمام تصاویر `assets/`
> مستقیماً با آدرس خودشان و بدون عبور از دروازه قابل دانلودند، و کد صفحه هم قابل
> مشاهده است. این صفحه فقط جلوی بازدیدکننده اتفاقی را می‌گیرد.
>
> برای محافظت واقعی سایت باید پشت یک سرور منتشر شود (Cloudflare Pages + Access یا
> یک Cloudflare Worker). چون `github.io` دامنه گیت‌هاب است و به کلادفلر اضافه نمی‌شود،
> آن مسیر یعنی از دست دادن آدرس `github.io`.
