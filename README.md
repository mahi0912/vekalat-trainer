# مربی آزمون وکالت مرکز وکلا

اپلیکیشن وب استاتیک برای تمرین ۹۱۰ سؤال واقعی آزمون وکالت مرکز وکلا (۱۳۹۸ تا ۱۴۰۴) همراه با
تصویر اصل دفترچه و تحلیل حقوقی چهارگزینه‌ای.

## ساختار پروژه

```
site/
  index.html          رابط کاربری و منطق آزمون
  bank.js             بانک سؤال (window.BANK_DATA) — همان چیزی که صفحه بارگذاری می‌کند
  bank.json           همان داده به شکل JSON خام (منتشر نمی‌شود، فقط برای کار روی داده)
  AUDIT_REPORT.json   گزارش ممیزی بانک سؤال
  assets/<سال>/*.jpg  تصاویر صفحات دفترچه
scripts/
  verify_site.py      اعتبارسنجی بانک سؤال و تصاویر
.github/workflows/
  deploy.yml          پایپلاین CI/CD انتشار روی GitHub Pages
```

## اجرای محلی

چون صفحه فایل‌ها را با مسیر نسبی بارگذاری می‌کند، کافی است یک وب‌سرور ساده بالا بیاورید:

```bash
python3 -m http.server 8000 --directory site
# سپس http://localhost:8000
```

## اعتبارسنجی

```bash
python3 scripts/verify_site.py
```

بررسی می‌کند که بانک سؤال دقیقاً ۹۱۰ سؤال داشته باشد (`index.html` روی همین عدد قفل است)،
شناسه‌ها تکراری نباشند، کلید هر سؤال بین ۱ تا ۴ باشد و تمام تصاویر ارجاع‌شده روی دیسک موجود باشند.

## انتشار

هر پوش روی شاخه `main` به‌صورت خودکار پایپلاین را اجرا می‌کند:

1. **verify** — اجرای `scripts/verify_site.py`. اگر شکست بخورد، دیپلوی انجام نمی‌شود.
2. **deploy** — انتشار محتویات `site/` روی GitHub Pages.

اجرای دستی هم از تب **Actions → Deploy to GitHub Pages → Run workflow** ممکن است.

پایپلاین از `GITHUB_TOKEN` داخلی خود Actions استفاده می‌کند و به هیچ توکن شخصی نیاز ندارد.

> ⚠️ فایل `secrets.md` در `.gitignore` قرار دارد و نباید هرگز کامیت شود.
