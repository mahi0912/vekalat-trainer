# تحلیل‌های بازنویسی‌شده

هر فایل `<سال>.json` تحلیل‌های بازنویسی‌شدهٔ آن سال را نگه می‌دارد، کلیددار با شناسه سؤال.
`scripts/build_data.py` این‌ها را روی تحلیل‌های قدیمی `analysisV2` سوار می‌کند: هر سؤالی که
اینجا ورودی داشته باشد، نسخه بازنویسی‌شده را می‌گیرد و بقیه فعلاً نسخه قالبی قدیمی را.

## ساختار هر ورودی

| کلید | معنا |
|---|---|
| `keyAtExam` | کلید رسمی دفترچه در سال برگزاری |
| `keyToday` | پاسخ صحیح بر مبنای قانون امروز |
| `lawChanged` | آیا `keyToday` با `keyAtExam` فرق دارد |
| `changeNote` | توضیح تغییر قانون — هم وقتی پاسخ عوض شده، هم وقتی قانونِ مرتبط اصلاح شده ولی نتیجه ثابت مانده |
| `legalBasis` | مستند اصلی |
| `summary` | جمع‌بندی حکم |
| `options` | چهار تحلیل، هرکدام ۲ تا ۳ خط، مخصوص همان گزینه |
| `sources` | مواد و قوانین استنادشده |
| `reviewedAt` | تاریخ بازبینی |

**مبنای نمره‌دهی `keyToday` است.** اگر با کلید دفترچه فرق داشته باشد، اپ هر دو را
به کاربر نشان می‌دهد و تفاوت را توضیح می‌دهد.
